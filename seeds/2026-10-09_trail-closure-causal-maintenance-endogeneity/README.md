# Trail Closure Causal Inference Under Maintenance Scheduling Endogeneity

## Research Question

**Do trail segments causally *require* joint maintenance, or do they co-close only because maintenance crews endogenously schedule them together to minimize travel time?**

## The Non-Obvious Angle

Standard causal inference assumes treatment assignment is either exogenous or confounded by observed/unobserved variables. Here, the "treatment" (two segments closing simultaneously) is **endogenous to the maintenance decision-making process itself**.

- **Causal scenario**: Segments A and B share a drainage system; they structurally *must* be maintained together.
- **Endogenous-confounding scenario**: Segments C and D are geographically close; crews *choose* to schedule them together to save travel time, creating spurious co-closure correlation.

The challenge: **closure timing alone cannot distinguish these**. Both produce co-closure events. We must infer causal vs. administrative from *temporal patterns*:

- **Causal link**: Segments close together repeatedly with variable gaps (structural failure detected, then repair delayed or staggered).
- **Administrative endogeneity**: Segments close together *consistently* with tight, uniform gaps (same crew, same day, every time).

## Method

We compute a **clustering score** for each segment pair:

```
clustering_score = (co_closure_rate) / (1 + avg_temporal_gap_in_days / 30)
```

This exploits the fact that:
- Causal links show **moderate clustering** with **variable gaps** (natural failures are irregular).
- Administrative endogeneity shows **high clustering** with **tight, uniform gaps** (scheduled maintenance is repeatable).
- Spurious pairs show **low clustering** or **loose/irregular gaps**.

## Data

**Synthetic**, designed to encode the causal structure:
- **Segment A**: Always closes (natural erosion)
- **Segment B**: 85% co-closes with A (causal), 30% spurious admin co-closure
- **Segments C–D**: 70% co-close via crew scheduling (pure endogeneity, no causation)
- **Segments E–F**: Random standalone closures

200 closure events over ~1 year, with date-based co-occurrence.

## Limitation

This approach detects *signatures* but cannot prove causation without:
1. Explicit crew assignment logs (to adjust for scheduling decisions).
2. Maintenance work orders (to confirm whether repairs are actually needed jointly).
3. Counterfactual data (what if crews were assigned differently?).

The real solution would require observational causal inference (e.g., backdoor adjustment on crew assignments), but that data is not available here.

## What Makes This Non-Obvious

Causal inference typically assumes confounders are external or pre-existing. Here, the confounder (crew scheduling preference) is *generated by* the same system producing the treatment (co-closure). This creates a feedback loop: crew scheduling *causes* co-closures, which then *create* an apparent structural dependency.

The seam: standard causal methods expect the causal graph to be acyclic. This one isn't—it's a *policy endogeneity* problem.
