# Competitive Birdwatching Species Co-Rarity Detection via Co-Absence Graph Clustering

## Question

Can we infer which birdwatching species are ecologically paired (co-require similar rare habitats) by clustering a graph built from **co-absence patterns** in sparse sighting logs, when traditional co-presence networks fail due to sparsity?

## Non-Obvious Angle

Standard network analysis in ecology clusters species by **co-occurrence**: if species A and B are often sighted together, they're likely habitat-paired. But in competitive birdwatching, sightings are sparse and geographically scattered. Co-presence edges become noisy and weak.

This project inverts the signal: instead, we build edges between species that are **jointly absent** on the same dates. The insight is that if two rare species are both missing on many dates, they likely share the same habitat/season constraints—they're both unavailable for the same ecological reasons.

The graph is generated by:
1. For each date, identify which species were NOT observed.
2. Count how many dates each pair of species were jointly absent.
3. Build a weighted graph where edge weight = co-absence frequency.
4. Cluster via modularity optimization.

The result: communities that align with true ecological habitat groupings, recovered from the *negative space* of the sighting data.

## Data

**Synthetic**, generated inline. The dataset models:
- 12 species across 4 habitat types (wetland, field, water, woodland).
- 365 daily observation records with rarity probabilities per species.
- Realistic sparsity: rare species appear ~30–45% of days; common species ~90%+.
- Joint absence is genuine: if two species share habitat, they're constrained by the same seasonal/weather factors and jointly absent on same dates.

## Limitation

This is a proof-of-concept on synthetic data where the true habitat groups are known. Real birdwatching data would require:
- Sighting logs from eBird or similar (public, but requires aggregation).
- Ground truth on ecological habitat pairing (literature-based).
- Validation that co-absence clustering outperforms co-presence clustering on sparse real data.

The synthetic data demonstrates the **technique** works when the domain constraint (sparsity) is real.

## What's Real vs. Synthetic

- **Synthetic**: The sighting dataset is generated to have the right statistical structure (rarity scores, habitat affinity, co-absence clustering).
- **Real technique**: The co-absence graph construction and modularity clustering are genuine network algorithms (networkx).
- **Real insight**: On sparse data, co-absence edges are less noise-prone than co-presence edges because absence is a stronger signal when data is sparse.
